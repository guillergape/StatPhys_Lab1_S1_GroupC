\section{\texorpdfstring{Large-$N$}{Large-N} approximations (Part 2 k)}
\label{app:largeN}
For $N=10^{23}$ every answer of Table~\ref{tab:largeN} is computed in terms of offsets $d=k-N/2$ (\texttt{solve\_part2\_k}) with:
\begin{itemize}
\item small $k\ll N$: $\ln\binom{N}{k}=\sum_{i=0}^{k-1}\ln(N-i)-\ln k!\simeq k\ln N-\ln k!-\frac{k(k-1)}{2N}$;
\item near the peak (Stirling, see Part~1\,e): \[P(N/2)\simeq\sqrt{\frac{2}{\pi N}},\qquad \frac{\Delta S_{k_1k_2}}{k_B}\simeq-\frac{2(d_1^2-d_2^2)}{N};\]
\item intervals: $P(d_1\le k-N/2\le d_2)\simeq\frac12\bigl[\operatorname{erf}\frac{d_2+1/2}{\sigma\sqrt2}-\operatorname{erf}\frac{d_1-1/2}{\sigma\sqrt2}\bigr]$, with $\sigma=\sqrt N/2=1.58\times10^{11}$.
\end{itemize}
The tests check each approximation against the exact value at $N=10^4$--$10^6$ (relative differences between $10^{-6}$ and $10^{-3}$, shrinking as $N$ grows).
